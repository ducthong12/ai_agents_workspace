## Automatic AI documentation
After changing code, create or update a Markdown document in docs/ai/ before your final reply. Include: the user request, changed behavior, relevant files, rationale, tests actually run and known limitations. Use a stable descriptive filename for the feature. Do not include credentials, raw prompts, customer data or full transcripts. Update existing documentation instead of duplicating it. Do not claim tests that were not run. AI Workspace automatically indexes docs/ai/ while running.
